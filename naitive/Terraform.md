# 테라폼
코드형 인프라(IaC) 제품으로, 여러 클라우드, 네트워크, 프라이빗 데이터 센터 및 SaaS 환경의 인프라 구셩 요소를 프로비저닝 할 수 잇도록 통합된 인프라 라이프사이클 관리 인터페이스와 단일 워크플로를 제공한다.

## 특징
1. 절차형 언어가 아닌 선언형 언어를 사용한다.(사용자는 인프라 리소스의 원하는 최종 상태를 정의하면 된다.)
2. 실행 계획을 자동으로 생성하고 리소스 간 종속성을 파악하여 구성 요소를 올바른 순서대로 프로비저닝한다.
3. 사용 시 사람이 읽기 쉬운 구성 파일을 작성하여 인프라 구성 요소를 생성, 업데이트 및 삭제할 수 있다.
4. 구성 파일은 버전 관리, 재사용 및 공유가 가능하다.
5. 컴퓨팅 및 스토리지 리소스, S3 버킷과 같은 하위 수준 구성 요소나 DNS SaaS 기능과 같은 상위 수준 구성 요소도 관리한다.
