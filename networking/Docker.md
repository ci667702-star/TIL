# Docker compose
여러 컨테이너로 구성된 애플리케이션을 정의하고 실행하는 도구이다.

## 사용하는 이유
1. 간소화된 제어
    - 하나의 YAML 파일에서 여러 컨테이너로 구성된 앱을 정의하고 관리하여 오케스트레이션 및 복제를 간소화한다.
2. 효율적인 협업
    - 공유 가능한 YAML 파일은 개발자와 운영팀 간의 원활한 협업을 지원하여 워크플로 및 문제 해결 능력을 향상시키고 전반적인 효율성을 높인다.
3. 신속한 애플리케이션 개발
    - 컨테이너 생성에 사용된 구성을 캐시하여, 변경 사항이 ㅇ벗는 서비스를 다시 시작하는 기존 컨테이너를 재사용한다.

# Docker Container를 삭제하면?
Docker container는 휘발성이므로 삭제하면 안에 있는 데이터까지 같이 삭제된다.
